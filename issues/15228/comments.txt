----- 2024-07-08 kaiwas -----
I noticed this problem in version 0.22, but it seems to be reproducible in version 0.21.
And it really comes down to the material chosen.
If you use a metal profile, then everything is fine.
But if you choose concrete, then something is not working correctly.
There is no “column” preset for a concrete column. The problem is probably related to this.

----- 2024-07-11 yorikvanhavre -----
Normally both column and beam modes should save their own settings separately... There seems to be a problem there indeed, I'll have a better look

*EDIT* Just checked, it doesn't. Saved preset settings are saved at the same place for both beams and columns. So this is something to be fixed, preset settings should be saved in two separate subsets, one for beams and one for columns. However, I'd rather do this after 1.0 to not introduce new last-minute bugs.

Also, I think when starting the tool using the beam or column buttons, the beam/column mode is implicit, so the beam/column controls in the task panel should be hidden.
