----- 2024-04-29 xorxx -----
I did some debugging on this problem, but I am not deep enough in code to provide a final solution. But some hints from my side.

At least a part of the problem is inside `.\Mod\Fem\femsolver\elmer\writer.py`. At several places in code a name for the sif-file name-field is created by only using `name `property of objects. This leads to duplicates because `name `property has values like "solid1" or "face1" for multiple objects. To resolve this I tried to modify function `getAllBodies` as follows by replacing references to `obj.Name` with `obj.FullName`. I added a string replace for "#" because this leads to problem in SIF file.

```
 def getAllBodies(self):
     obj = self.getSingleMember("Fem::FemMeshObject")
     bodyCount = 0
     prefix = ""
     if obj.Part.Shape.Solids:
         prefix = "Solid:"+obj.FullName.replace("#",":")
         bodyCount = len(obj.Part.Shape.Solids)
     elif obj.Part.Shape.Faces:
         prefix = "Face:"+obj.FullName.replace("#",":")
         bodyCount = len(obj.Part.Shape.Faces)
     elif obj.Part.Shape.Edges:
         prefix = "Edge:"+obj.FullName.replace("#",":")
         bodyCount = len(obj.Part.Shape.Edges)
     return [prefix + str(i + 1) for i in range(bodyCount)]
```

Modifications like this are needed in other places too. I am just not familiar enough with SIF file structure to see if this is really correct what I am doing here. At least my model is not fully running as expected with this modifications, but it gets a bit better.

Maybe this helps one of the specialist by solving this problem. Thanks for all your contributions to this great piece of software! I convinced my boss to donate some money to FreeCAD development. It is definitely worth!
