### Problem description

Steps to reproduce:

- define property set without `Pset_` prefix using with some properties in  CustomPsets.csv in $USERAPPDATA/BIM folder (sample file here: 

[CustomPsets.csv](https://github.com/user-attachments/files/19394274/CustomPsets.csv)

- open BIM_IfcProperties dialogue in any file with BIM objects
- select one BIM object
- choose `Add propert set ...`
- the custom property set is not named correctly
- it is not possible to assign that custom property set to the object

See behavior in the video:

https://github.com/user-attachments/assets/1d8153cb-5e7e-4647-be92-e873649065de


Even if the property set is named with `Pset_` prefix, the name is displayed incorrectly in the drop down menu (e.g. Free C A D instead of FreeCAD)

### Anything else?

1. In practice, the `Pset_` prefix should be used only for property sets defined by the IFC schema. It is highly recommended to NOT use `Pset_` prefix for custom property sets. It is almost considered a crime :). FreeCAD's functionality should work without the `Pset_` prefix.

2. FreeCAD wiki breaks the above mentioned IfcGentleman's rule - showing Pset_FreeCAD as an example. This should be fixed.
